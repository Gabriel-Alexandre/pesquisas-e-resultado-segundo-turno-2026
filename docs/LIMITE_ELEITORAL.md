# Limite eleitoral

A eleição de 2026 terminou em 25/10 e o resultado usado aqui é o oficial do TSE. Nada neste projeto recomenda voto, julga a intenção de ninguém ou declara vencedor de algo que ainda vai acontecer. As probabilidades são a chance que os números davam **antes** da votação, calculadas depois dela.

"Fraude" aparece só como o nome de uma hipótese (a lente F da leitura), testada com o mesmo rigor e com espelho para os dois candidatos, nunca como conclusão.
